# Samsung Digital Content Plan — AI Agent

Автоматизация мастер контент-плана: агент сам разносит новые кампании по каналам/назначениям,
пересчитывает дедлайны по правилам (не единым флэт-правилом), находит конфликты и риски,
показывает наглядный календарь и бюджет, выдаёт недельный дайджест для менеджера.

## Что делает

1. Читает `samsung-digital-content-plan-template.xlsx` (все 4 вкладки: контент-план, правила
   дедлайнов, каналы/назначения, трекинг) — либо принимает вводные от менеджера прямо в
   приложении (модель, тип, дата старта).
2. Сам подбирает канал, назначение (дистрибьютора/маркетплейс) и формат креатива по матрице
   «канал → назначение», с ротацией между партнёрами, чтобы покрытие не проседало на одном.
3. Пересчитывает дедлайны **по правилам своего типа кампании** (Промо-запуск / Always-on /
   Медийка / Retail support / Маркетплейс) — вместо единого правила −14/−7/−3, которым были
   посчитаны дедлайны в исходном файле.
4. Сдвигает дедлайн на предыдущий рабочий день, если он падает на выходной; добавляет +1 день
   на согласование, если назначение — дистрибьютор (Technodom / Sulpak / Mechta / Evrika).
5. Проверки: просроченные дедлайны, дедлайны на этой неделе, кампании без креатива, перегруз
   недели (>4 запуска), медийка без перформанс-поддержки, модели/каналы/дистрибьюторы без
   покрытия, баланс бюджета перформанс/медийка.
6. Отдельно подсвечивает, где именно исходный файл посчитал дедлайн неверно (флэт-правило vs
   правило по типу) — это и есть найденная в задании ошибка.
7. Пересчёт мгновенный при любой правке — смене даты, статуса, добавлении кампании — без
   ручного шага.

## Как менеджер работает с этим каждый день

Открой **`index.html`** (двойной клик, работает в любом браузере, сервер не нужен):

- Весь контент-план, недельный календарь, диаграмма бюджета по моделям, дайджест и риски —
  одним экраном; 7 кликабельных KPI-карточек сверху с разбором по клику
- Добавление кампании — 3 поля (модель, тип, дата старта), опционально выбор конкретных
  каналов/дистрибьюторов вручную
- Загрузка Excel — новый месяц целиком, в один клик
- Даты и статус редактируются прямо в таблице — дедлайны пересчитываются на лету
- Данные сохраняются в браузере автоматически; «Экспорт/Импорт JSON» — перенос/резервная копия

`engine.py` — тот же набор правил как воспроизводимый пакетный пайплайн (для CI/автоматизации,
без браузера). `index.html` — интерфейс на каждый день.

## Как запустить

```bash
pip install openpyxl
python engine.py
```

Меняете `INPUT_PATH` в начале `engine.py` на файл следующего месяца — весь пересчёт и все
проверки берутся из самого файла (правила, матрица каналов), а не захардкожены, так что скрипт
отработает на новых данных без переделки.

## Что на выходе

- `content-plan-corrected.xlsx` — план с пересчитанными датами и подсветкой (красный =
  просрочено, жёлтый = дедлайн на этой неделе)
- `calendar.html` — интерактивный календарь по неделям
- `conflict-report.md` — отчёт проверок с приоритетами
- `weekly-digest.md` — дайджест для менеджера: что горит / что делать на неделе / где дыры
- `output.json` — сырые данные пересчёта

## Используемые инструменты

- **Claude** — сборка движка и интерфейса, промпт-инжиниринг структуры проверок
- **Python** (openpyxl) — чтение/запись Excel, вся бизнес-логика пересчёта
- **Vanilla HTML/JS, SheetJS** — интерфейс и загрузка Excel прямо в браузере, без сборки

## Про промпты (кратко)

Промпты строились вокруг трёх задач: (1) вычитать из Excel реальные правила дедлайнов и
матрицу каналов, а не хардкодить их, (2) прогнать пересчёт и все проверки конфликтов на
основе этих правил, явно показав расхождение с флэт-расчётом исходного файла, (3) собрать то
же самое как интерактивный инструмент, где менеджер вводит только минимум, а остальное решает
агент. Точные формулировки не привожу дословно — общий подход готова разобрать устно на защите.

## Найденная ошибка в исходном файле

Дедлайны в `samsung-digital-content-plan-template.xlsx` были посчитаны единым правилом −14/−7/−3
для всех 12 кампаний. По вкладке «2. Правила дедлайнов» у пяти типов кампаний разные сроки
(например, «Медийка» требует −21/−10/−5, а не −14/−7/−3 — на видеопродакшен нужно больше
времени). После пересчёта по верным правилам 8 из 12 кампаний получили другой (более ранний)
дедлайн брифа — подробности в `conflict-report.md`, раздел «Расхождение с исходным файлом».
